# LiberInk Privacy Policy

## 1. General Provisions
This Privacy Policy outlines the rules for the collection, processing, storage, and protection of user data within the LiberInk ecosystem.

## 2. Categories of Collected Data
- **Account Data:** Login (username) and password.
- **User Data:** Text documents, notes, and materials created or uploaded by the user to the LiberInk system.

## 3. Purpose of Data Processing
- Enabling authentication and access to the service.
- Providing functionality for creating, editing, and saving documents.

## 4. Minimization Principle
The system collects only the data strictly necessary for the editor's operation. We do not collect usage telemetry or user location data.

## 5. Data Protection and Storage
- User passwords are **not stored in plain text**. Irreversible hashing (e.g., BCrypt/SHA256 algorithms) is used.
- All data is stored in a relational database (MySQL). Access to the database is restricted to authorized administrators only.

## 6. Data Deletion
Upon a user's request, their account and all texts created by them are permanently deleted from the database.
